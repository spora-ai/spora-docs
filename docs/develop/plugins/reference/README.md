# Plugin reference

One page per plugin in the `spora-ai` GitHub org, each covering what it adds, how to install it, what credentials it needs, and the parameters of every tool it ships. Start with **[Develop → Plugins](/develop/plugins)** for what a plugin is and how to install one; the full inventory of shipped plugins, including the three that do not have a page here, is in [Reference: shipped plugins](/develop/plugins/#reference-shipped-plugins).

- **[Calendar](/develop/plugins/reference/calendar)** — CalDAV read/write — iCloud, Fastmail, Nextcloud, Radicale, Baïkal, Google Calendar
- **[Custom skills](/develop/plugins/reference/custom-skills)** — principal-scoped custom skills, authored by hand or by the agent, served through core's `skill` tool
- **[Email](/develop/plugins/reference/email)** — SMTP send + IMAP read — 11 operations
- **[Memories](/develop/plugins/reference/memories)** — persistent memory storage for agents and users, plus the Memories admin panel
- **[MiniMax](/develop/plugins/reference/minimax)** — image, speech, music, and video generation
- **[Muse](/develop/plugins/reference/muse)** — Meta Muse vendor home on a single Meta Model API key
- **[OpenAI Image](/develop/plugins/reference/openai-image)** — OpenAI-compatible image generation against any compatible provider
- **[Plugin skeleton](/develop/plugins/reference/plugin-skeleton)** — minimal template — start here for new plugins
- **[Semantic Scholar](/develop/plugins/reference/semantic-scholar)** — academic paper search and metadata (free, no key)
- **[Serper](/develop/plugins/reference/serper)** — Google Search via Serper.dev — 9 operations
- **[Staan](/develop/plugins/reference/staan)** — EU-hosted web search
- **[Tavily](/develop/plugins/reference/tavily)** — AI-native web search (LLM-optimised answer + ranked sources)
- **[Typst](/develop/plugins/reference/typst)** — compile Typst source to PDF/PNG/SVG
- **[Weather](/develop/plugins/reference/weather)** — current conditions, forecasts, astronomy (WeatherAPI.com)
- **[World News](/develop/plugins/reference/worldnews)** — top news by country and full-text news search
- **[Zernio](/develop/plugins/reference/zernio)** — social-media scheduling and publishing across 15+ networks
