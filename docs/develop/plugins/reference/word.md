# The Word plugin is now the Office plugin

The package is now **`spora-ai/spora-plugin-office`**, and its slug is `office`. Its page is at **[Office](/develop/plugins/reference/office)**.

The old package `spora-ai/spora-plugin-word` is **deprecated but still published** — it is not deleted.
